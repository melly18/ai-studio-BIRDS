# 1. 정제된 결제 DataFrame 표준 컬럼명/타입 표
- 모듈: data_processing.py
- 반환 과정:
    1. load_billing_csv(file_path: str → df: DataFrame)
    2. load_saas_catalog(catalog_path: str → catalog: dict[str, Any])
    3. mask_pii_data(df: DataFrame → masked_df: DataFrame)
    4. clean_billing_csv(masked_df: DataFrame, catalog: dict → (clean_df: DataFrame, warnings: list[dict]))
- 최종 반환: clean_df: DataFrame, warnings: list[dict]
- 후속 모듈 전달: quant_analysis.py에는 clean_df만 전달한다. warnings는 전달하지 않는다.

## 1. clean_df 구조
- 타입: pandas DataFrame (행 1개 = 정제를 통과한 결제 기록 1건)
- 열 순서와 타입은 아래 표와 같다.

| 컬럼명 | 타입 | 정제 규칙 |
|---|---|---|
| tx_id | str | 앞뒤 공백 제거. 중복 tx_id는 첫 행만 남기고 제외. 비어 있으면 TX-AUTO-001부터 순번 발급 |
| billing_date | str | YYYY-MM-DD 형식으로 통일. 지원 형식 5가지(YYYY-M-D, YYYY/M/D, YYYY.M.D, YYYYMMDD, YYYY년 M월 D일) 외에는 제외 |
| service_name | str | 카탈로그의 service_name·alias(대소문자 무시)를 표준 service_name으로 변환. 카탈로그에 없는 이름은 그대로 유지. 빈 값은 제외 |
| department | str | 앞뒤 공백 제거. 빈 값은 "미상"으로 보정 |
| billing_cycle | str | "월간" 또는 "연간" 두 값만 허용. monthly/month → 월간, annual/yearly → 연간. 그 외 값은 제외 |
| seat_count | int | 1 이상. 변환 실패 또는 0 이하이면 제외 |
| active_users | int | 0 이상 seat_count 이하. 빈 값·음수는 0으로, seat_count 초과는 seat_count로 보정 |
| billing_amount_krw | int | 0 이상 정수(원). 쉼표, "원", "₩" 제거 후 변환. 빈 값·변환 실패·음수는 제외 |
| card_holder_pii | str | 마스킹된 값 "[REDACTED]". clean_billing_csv는 이 값을 수정하지 않고 그대로 유지 (마스킹은 mask_pii_data에서 수행) |
| monthly_cost_krw | int | 월간 환산 비용(원). 월간이면 billing_amount_krw 그대로, 연간이면 billing_amount_krw ÷ 12를 반올림 |

### 보장 조건
- 위 10개 컬럼이 모두 존재하며 결측값(NaN)이 없다.
- 숫자 컬럼 4개(seat_count, active_users, billing_amount_krw, monthly_cost_krw)는 int 타입이다.
- tx_id는 중복이 없다.
- seat_count ≥ 1, 0 ≤ active_users ≤ seat_count이므로 quant_analysis.calculate_seat_leakage의 검증(결측·음수·seat_count 0·active_users 초과)을 통과한다.

### 빈 결과
- 입력이 None이거나 0행이면 위 10개 컬럼을 가진 빈 DataFrame을 반환한다.

### 참고
- 제외된 행 때문에 인덱스는 0부터 연속되지 않을 수 있다 (reset_index를 하지 않음).

| 키 | 타입 | 설명 |

- df가 None 또는 행이 0개: (빈 DataFrame(표준 컬럼 10개), [])
- 경고가 없는 정상 입력: (clean_df, [])


# 2. quant_analysis.py가 반환할 표준 키 구조

## 1. calculate_seat_leakage
- 입력: clean_df: DataFrame (service_name, seat_count, active_users, monthly_cost_krw 필수)
- 반환: seat_leakage: list[SeatLeakage]
- 구조: SeatLeakage(frozen dataclass) 1개 = 서비스 1개

| 필드 | 타입 | 설명 |
|---|---|---|
| service_name | str | 서비스(툴) 이름 |
| inactive_seats | int | 유휴 좌석 수 = seat_count - active_users (서비스 내 모든 결제 기록 합산) |
| wasted_spend | int | 추정 월간 낭비 금액(원) = round(monthly_cost_krw × inactive_seats ÷ seat_count)를 행마다 계산해 서비스별로 합산 |

- 정렬: clean_df에서 서비스가 처음 등장한 순서
- 빈 DataFrame 입력 시: []
- 예외: TypeError(DataFrame 아님), KeyError(필수 컬럼 누락), ValueError(결측·음수·seat_count 0·active_users > seat_count)
- 예시:
    [SeatLeakage(service_name="Slack", inactive_seats=12, wasted_spend=96000)]

## 2. detect_duplicate_tags
- 입력: clean_df: DataFrame (service_name 필수), catalog: dict (tools 키 필수)
- 반환: duplicate_pairs: list[DuplicatePair]  (DuplicatePair = list[str])
- 구조: 중복 서비스 쌍 1개 = 문자열 리스트 1개

| 인덱스 | 타입 | 설명 |
|---|---|---|
| [0] | str | 서비스명 1 (카탈로그의 표준 service_name) |
| [1] | str | 서비스명 2 (카탈로그의 표준 service_name) |
| [2:] | str | 두 서비스의 공통 category_tags (1개 이상, 서비스명 1의 카탈로그 태그 순서) |

- 대상: clean_df에서 실제 사용 중인 서비스(서비스명 또는 alias로 카탈로그 매칭)만
- 쌍 순서: 카탈로그 정의 순서, 같은 쌍은 한 번만 (A,B만 있고 B,A는 없음)
- 공통 태그가 없거나 입력/카탈로그가 비어 있으면: []
- 예외: TypeError(DataFrame 아님), KeyError(비어 있지 않은 clean_df에 service_name 없음)
- 예시:
    [["서비스A", "서비스B", "협업", "메신저"]]
